Privacy notice

Wealth Builder is a fictional, educational browser simulation. It has no account, contact form, payment flow, advertising, profiling, or first-party analytics.

Data used

Game calculations run in your browser. The current version does not send game decisions or financial values to an application backend. Do not treat the simulation as financial advice or enter real confidential information.
